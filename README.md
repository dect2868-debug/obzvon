# ZRP ОБЗВОН v2.3 — система обзвона

Улучшенная версия обзвона: сложнее списать/схитрить, удобнее для куратора.

## Запуск
Просто откройте `index.html` в браузере. Для общего доступа положите папку на любой хостинг
(Portal / GitHub Pages / любой сервер) — всё статическое, без базы данных.

## Версии и обновления
- Версия указана в шапке сайта, в `CONFIG.appVersion` (js/app.js) и в `version.json`.
- При раздаче по http сайт **сам проверяет наличие новой версии** (`version.json`) и
  показывает уведомление «Доступна новая версия — обновите страницу (Ctrl+F5)».
- Ссылки на CSS/JS имеют `?v=2.3` — после обновления файлов браузер гарантированно
  подхватит новую версию, без залипания кэша.
- Если скрипт всё же упадёт, ошибка не останется незаметной: сверху появляется красный
  баннер с текстом ошибки и подсказкой перезагрузить страницу.

## Как проводить обзвон
1. Участник открывает ссылку → нажимает **«Калибровка»**. Количество испытаний выбирает
   куратор в пульте: **6 / 10 / 20 / 50**, по умолчанию **50 — длинная проверка на
   внимательность**. При 6 — по одному каждого вида (случайный порядок): клавиша, цель,
   удержание, математика, память, Струп; при 10+ виды чередуются случайно.
   Провал любого — калибровка начинается заново.
2. Куратор вводит код доступа в «ПУЛЬТ КУРАТОРА» (текущий код: **`ZRP-Obzvon-2026`**,
   он же в `CONFIG.passcode` файла `js/app.js`) → **«Начать обзвон»**.
   Код на самой странице не показывается.
3. Во время обзвона испытания появляются каждые 6–20 секунд (темп ускоряется к концу сессии).
   Виды (сложные, случайные):
   - **Клавиша** — нажать указанную клавишу за 4,5 с (работает при любой раскладке);
   - **Цель** — кликнуть по движущейся цели (после 4-го испытания цель меньше и быстрее);
   - **Удержание** — держать пробел 1,5–3 с (раньше отпустил — провал);
   - **Математика** — решить пример в уме и ввести ответ цифрами за 6 с;
   - **Память** — запомнить 4 символа (показ 1,7 с) и ввести их по порядку;
   - **Струп** — кликнуть по кнопке того цвета, КОТОРЫМ написано слово (цвет слова обманывает).

После 6-го испытания сессии таймауты всех видов сжимаются ещё на 20% — к концу обзвона
проверка становится заметно жёстче.
4. Куратор смотрит на «ЧИТОМЕРЯК» у участника (участник демонстрирует экран) и
   по кнопке **«Завершить»** получает вердикт: ЗАЧЁТ / СОМНИТЕЛЬНО / НЕЗАЧЁТ.
5. **«Отчёт»** скачивает JSON со всеми метриками, журналом нарушений, списком испытаний
   и фишками.

## Таблица результатов (всё на странице)
Раздел **«ТАБЛИЦА РЕЗУЛЬТАТОВ»** обновляется в реальном времени:
- **левая таблица** — метрики: концентрация, читомеряк, фокус, смены вкладок, срывы фокуса,
  лишние экраны, провалы испытаний, простой, копирование, DevTools, перезагрузки, средняя
  реакция, число нарушений;
- **правая таблица** — журнал каждого испытания: номер, вид (тег КАЛИБР/СЕАНС), итог
  (ВЕРНО/ПРОВАЛ + причина) и время реакции в мс;
- сверху сводка: «N испыт. · верно K · ср. реакция X мс».
Журнал переживает закрытие итогов (виден до нового обзвона) и попадает в JSON-отчёт.

## Пауза и завершение участником
Во время обзвона у участника есть панель: **«⏸ Пауза»** (переключается в «▶ Продолжить»)
и **«■ Завершить обзвон»** (с подтверждением). После завершения показываются итоговая
таблица и **фишки** — достижения за обзвон:
- ⚡ СКОРОСТНОЙ (реакция < 350 мс), 🎯 ТОЧНЫЙ (без провалов), 🛡 ЖЕЛЕЗНЫЙ ФОКУС (≥ 95%),
  ✨ ЧИСТЫЙ ЛИСТ (0 нарушений), 🏃 МАРАФОН (≥ 10 испытаний), 🔥 РАСКУСОТКА (≥ 20),
  😌 СПОКОЙСТВИЕ (вкладки не менял), 💪 БОЕВОЙ ДУХ (дошёл до конца под штрафами).
Фишки копятся в общей статистике и попадают в отчёт.

## Журнал событий
Раздел **«ЖУРНАЛ СОБЫТИЙ»** пишет всё подряд, новое сверху: старт/пауза/продолжение
обзвона, каждое испытание с результатом и реакцией, нарушения со штрафами, блокировки,
разблокировки, перезагрузки и итог с вердиктом. Во время сессии журнал сохраняется —
переживает перезагрузку страницы (восстанавливается вместе с сессией).

## Как считается концентрация
`Концентрация = фокус (35%) + скорость реакции к личной базе (30%) + (100 − читомеряк) (35%)`

- **Фокус** — доля времени, проведённого на странице во время обзвона;
- **Реакция** — среднее время ответа относительно базы, замеренной на калибровке
  (быстрее базы — не выше 100%, медленнее — падает). Честный замер: у «удержания»
  вычитается сам интервал удержания, у «памяти» — время показа, поэтому цифры
  не раздуваются до секунд;
- **Читомеряк** — штрафы за нарушения.

Концентрация и читомеряк обновляются мгновенно: любое нарушение подсвечивает карточку
метрики красной вспышкой.

**Концентрация не сбрасывается** после завершения обзвона и после провала — финальные
цифры (концентрация, читомеряк, журнал) остаются на экране до старта нового обзвона.
Обнуление происходит только при нажатии «Начать обзвон» — начинается чистая сессия.

## Средняя концентрация по всем обзвонам
После завершения каждого обзвона его итоговая концентрация добавляется в накопительную
статистику (последние 20 обзвонов) — карточка **«СРЕДНЯЯ КОНЦЕНТРАЦИЯ»** показывает среднее
и динамику к прошлому разу (▲ рост / ▼ падение). Данные хранятся в браузере участника
(`localStorage`); после перезагрузки страницы сохраняются. Средняя попадает в итоговую
таблицу и в JSON-отчёт.

## Что засчитывается как нарушение
| Событие | «Читомеряк» |
|---|---|
| Уход со вкладки / потеря фокуса | +4 (+8 во время испытания) |
| Провал испытания внимания | +8 |
| DevTools (F12 / Ctrl+Shift+I…) | +7…+8 |
| Второй монитор / резкий переезд окна | +10 |
| Смена устройства/браузера в сессии | +15 |
| Перезагрузка страницы (в т.ч. F5) | +6 |
| Попытка скриншота (PrintScreen) | +5 |
| Копирование / буфер обмена | +3 |
| Простой без действий (>65 с) | +2 |
| Изменение масштаба | +2 |
| Выход из полноэкранного режима (если включено) | +3 |

При достижении порога (по умолчанию 60%) участника **блокирует** — снимает куратор кодом.
Счётчик «читомеряка» при этом НЕ обнуляется.

## Защита от сброса
- F5 / Ctrl+R заблокированы во время сессии;
- даже если перезагрузить силой — сессия восстанавливается из `localStorage`,
  а нарушитель получает ещё +6 и запись в журнал;
- DevTools, исходник страницы (Ctrl+U), печать, сохранение — блокируются;
- контекстное меню, выделение и копирование отключены.

## Настройка
Файл `js/app.js`, блок `CONFIG` в начале:
- `passcode` — код куратора (сейчас `ZRP-Obzvon-2026`; **смените на свой**);
- `calibCount` — число испытаний калибровки по умолчанию (сейчас `50`);
- `threshold` — порог блокировки (можно менять и из панели куратора);
- `CH_TIMEOUTS` — таймаут каждого вида испытаний (мс);
- `idleLimit` — время простоя до штрафа.

Название сообщества — в `index.html`, заголовок `<h1>`.
Логотип — файл `assets/logo.svg` (замените на свой).

## Контроль копирования кода
- интерфейс собирается динамически, тексты журнала экранируются;
- исходники можно заминифицировать (например, minifier.app) и загрузить minified-версию —
  читать станет заметно сложнее;
- страница закрыта от индексации (`noindex`).

## Браузеры
Chrome / Opera / Яндекс / Edge / Firefox. Мобильные версии поддерживаются,
но для честного обзвона лучше ПК + полный экран.
